# FORME — Gym T-shirt Store

A simple, responsive premium-style storefront built with plain HTML, CSS and JavaScript. No npm packages required.

## Run it in VS Code

1. Extract this folder.
2. Open the `ironform-store` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

   ```bash
   npm start
   ```

5. Open **http://localhost:3000** in your browser.

You can also open `index.html` directly or use the VS Code Live Server extension.

## Included
- Responsive premium storefront design
- Product grid with category filters
- Add-to-bag interactions
- Shopping bag drawer with quantity controls and remove action
- Cart saved in browser localStorage
- Demo checkout message

## Before accepting real orders
This is a front-end demo. Replace the sample product photos/details with your own product assets, add real inventory and size selection, and connect a secure backend plus a payment provider (such as Razorpay) for checkout. Do not collect or store card details in this front-end demo.

## Customise
- Product names, prices, categories and image URLs: `script.js`
- Colours, typography and layout: `styles.css`
- Brand name and page content: `index.html`
